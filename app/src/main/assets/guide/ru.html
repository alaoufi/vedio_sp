Моя видеотека — Руководство пользователя

Личная, работающая офлайн библиотека для скачивания и просмотра видео из TikTok, YouTube, Instagram и Snapchat. Ничего не покидает ваше устройство.

1. Активация

При первом запуске приложение запрашивает код активации. Ваше устройство показывает номер устройства; отправьте его разработчику и введите полученный код. Активация полностью офлайн — после неё не требуются ни учётная запись, ни интернет.

2. Конфиденциальность & блокировка приложения

Откройте Настройки, чтобы защитить приложение:

  • Блокировка приложения: задайте PIN-код, чтобы приложение запрашивало разблокировку при каждом открытии.
  • Отпечаток пальца / биометрия: разблокируйте отпечатком пальца вместо PIN-кода.
  • Блокировать скриншоты: запрещает скриншоты и запись экрана внутри приложения.
  • Скрыть из недавних: скрывает превью приложения в списке недавних приложений.

Личные видео: заблокируйте любой ролик, чтобы переместить его в скрытый личный раздел. Он исчезает из основной библиотеки и возвращается только после проверки по отпечатку пальца.

3. Скачивание видео

По ссылке

Скопируйте ссылку на видео из TikTok, YouTube, Instagram или Snapchat, затем нажмите кнопку + и выберите Скачать по ссылке — или поделитесь ссылкой напрямую в это приложение через меню «Поделиться» другого приложения.

По поиску

Нажмите значок поиска и введите ключевые слова для поиска в YouTube (и TikTok). Нажмите на результат, чтобы посмотреть его, или воспользуйтесь кнопкой скачивания.

Видео или аудио

При скачивании вы можете выбрать полное видео или только аудио. Аудиозаписи сохраняются как настоящие аудиофайлы и воспроизводятся с обложкой, а не с чёрным экраном.

Instagram и Snapchat открывают доступ только к публичным записям. Личные записи или записи, требующие входа, извлечь нельзя.

4. Библиотека

  • Вид сеткой / списком: переключите вид в меню ⋮ → Переключить вид.
  • Сортировка: по дате, названию, длительности, размеру или категории.
  • Фильтр: по источнику, типу медиа и сразу нескольким категориям — отметьте несколько категорий, чтобы показать только их и скрыть остальные.
  • Избранное: помечайте ролики как избранные и фильтруйте по ним.
  • Категории: упорядочивайте ролики по категориям; каждый ролик показывает свою категорию в виде чипа. Выберите несколько роликов, чтобы задать их категорию массово.

5. Плеер

  • Непрерывное воспроизведение: когда ролик заканчивается, следующий в текущем списке воспроизводится автоматически. Используйте Вперёд / Назад в меню ⋮.
  • Продолжение: воспроизведение продолжается с того места, где вы остановились.
  • Жесты: проводите вверх/вниз по левой половине для яркости, по правой половине для громкости.
  • Скорость: нажимайте кнопку скорости, чтобы переключать 0,5×–2×.
  • Блокировка управления: скройте элементы управления, чтобы избежать случайных нажатий.
  • Картинка в картинке & фоновое воспроизведение: продолжайте смотреть или слушать, пользуясь другими приложениями.
  • Масштаб: подгонка, увеличение или растягивание видео.
  • Закрыть плавающий текст: нарисуйте прямоугольник поверх экранного текста или водяного знака, чтобы скрыть его во время воспроизведения.

6. Вкладка YouTube без рекламы

В меню ⋮ откройте вкладку YouTube: чистый просмотрщик без рекламы. По умолчанию показываются тренды для арабского региона, Shorts можно скрыть одним переключателем, а также можно искать и переключать вид сеткой/списком. Это отдельная вкладка, которая никогда не заменяет вашу библиотеку.

7. Редактор изображений

Для сохранённых изображений вы можете обрезать, скрыть имя/водяной знак сплошным прямоугольником, добавить текст в любом месте и извлечь текст из изображения с помощью OCR (скопированного в буфер обмена). Фото сохраняются чисто, без артефактов перекодирования.

8. Редактирование роликов

В меню ролика ⋮ вы можете переименовать его, изменить его описание, задать его категорию, добавить его в избранное, переместить в личный раздел или удалить.

9. Резервное копирование & восстановление

В Настройках экспортируйте зашифрованную резервную копию вашей библиотеки, защищённую паролем, и восстановите её позже с тем же паролем. Храните пароль в надёжном месте — без него резервную копию открыть нельзя.

10. Настройки

  • Язык: выберите язык приложения.
  • Тема: системная, светлая или тёмная.
  • Только Wi-Fi: скачивать только по Wi-Fi.
  • Одновременные загрузки: сколько загрузок идёт одновременно.
  • Место сохранения: где хранятся загрузки.

Это всё. Приятного пользования вашей личной видеотекой.
