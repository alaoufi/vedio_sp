Aking Library ng Video — Buong Gabay ng Gumagamit

Isang pribado at offline-first na library para sa pag-download, pag-organisa at panonood ng iyong mga video. Ang iyong library, mga download, database at lisensya ay nasa iyong device lamang — walang inia-upload sa anumang server.

1. Pag-activate at libreng pagsubok

Gumagana ang app nang offline — walang account, walang pag-sign in sa internet.

  • Libreng pagsubok: awtomatikong nagsisimula ang 10-araw na libreng pagsubok sa unang paglulunsad. Magagamit mo ang bawat feature sa panahong ito.
  • Pagkatapos ng pagsubok: hihingi ang app ng activation code. Ang iyong mga download at setting ay naitatago — ang access lamang ang naka-pause hanggang mag-renew ka.
  • Pag-activate: ipinapakita ng activation screen ang iyong numero ng device. Ipadala ito sa nagbebenta at ilagay ang code na matatanggap mo, pagkatapos ay i-tap ang Activate.
  • Katayuan: buksan ang Settings → Subscription upang makita ang “Pagsubok · N araw na natitira”, “Aktibo · N araw na natitira”, o permanente.
Sa Google Play, maaaring awtomatikong mag-activate ang app sa sandaling maging aktibo ang iyong subscription — hindi na kailangan ng code.

2. Privacy at app lock

Lahat ay nasa ilalim ng Settings → Security:

  • App lock: magtakda ng PIN upang humingi ang app ng pag-unlock sa bawat pagbukas.
  • Fingerprint / biometric: mag-unlock gamit ang iyong fingerprint sa halip na mag-type ng PIN.
  • Harangan ang mga screenshot: pinipigilan ang mga screenshot at screen recording sa loob ng app.
  • Itago mula sa recents: itinatago ang preview ng app sa recent-apps switcher.

Mga pribadong video

I-lock ang anumang clip (mula sa ⋮ menu nito) upang ilipat ito sa nakatagong pribadong seksyon. Mawawala ito mula sa pangunahing library at babalik lamang pagkatapos ng pagsusuri ng fingerprint (buksan ang pribadong view mula sa ⋮ menu).

3. Pag-download ng mga video

Mula sa isang link

  1. Kopyahin ang link ng video.
  2. I-tap ang + na button → Download from link (o i-share ang link sa app na ito mula sa ibang app).
  3. I-tap ang Paste, pagkatapos ay Get info.
  4. Piliin ang buong video, video lamang, o audio lamang, pagkatapos ay i-download.

Sa pamamagitan ng paghahanap

I-tap ang search icon, i-type ang mga keyword, i-tap ang isang resulta upang i-preview ito, o gamitin ang download button nito.

Audio kumpara sa video

Ang mga audio download ay nase-save bilang totoong audio file at nagpe-play na may cover art (hindi itim na screen). Maaari ka ring pumili ng kalidad kapag nag-aalok ang pinagmulan ng ilang opsyon.

Kung saan napupunta ang mga file

Ang mga download ay pribadong iniimbak sa app. Sa Settings → Save location maaari mo ring ilagay ang isang kopya sa folder na pinili mo upang lumitaw ito sa iyong gallery/file manager.

4. Ang built-in na browser

Buksan ang + → Browser para sa isang pangkalahatang web browser na tumutukoy sa nada-download na media sa anumang page.

  1. I-type ang isang site o maghanap sa address bar.
  2. I-play o buksan ang video sa page.
  3. Kapag natukoy ang media, lilitaw ang isang Download (N) na button — i-tap ito, piliin ang item, at ito ay nada-download sa iyong library.
Patuloy na ini-scan ng browser ang page sa loob ng ilang segundo, kaya kung hindi agad lumitaw ang button, simulan ang video at maghintay saglit.

5. Pamamahala ng mga download

Buksan ang + → Downloads (o i-tap ang download banner sa library) upang makita ang aktibo at tapos na mga trabaho. Maaari mong i-pause, i-resume at i-retry. Ang naka-pause o naantalang mga download ay nagpapatuloy mula sa kung saan sila tumigil, at ang nabigong download ay awtomatikong nagre-refresh ng link nito at nagre-retry.

6. Ang library

  • Grid / list view: lumipat mula sa ⋮ → Toggle view.
  • Paghahanap: i-tap ang magnifier; nagsa-filter ito ng library nang live.
  • Pag-sort: ayon sa petsa, pangalan, tagal, laki, o kategorya (pinagpapangkat ang mga clip ayon sa kategorya).
  • Filter: ayon sa pinagmulan, uri ng media, at ilang kategorya nang sabay-sabay — lagyan ng tsek ang mga kategoryang ipapakita at ang iba ay itinatago. Ipinapakita ng entry na Kategorya kung ilan ang aktibo.
  • Mga paborito: markahan ang mga clip bilang paborito at i-filter sila.
  • Mga kategorya: ipinapakita ng bawat clip ang kategorya nito bilang isang chip. Pamahalaan ang mga kategorya mula sa ⋮ → Manage categories.
  • Pumili ng marami: pindutin nang matagal ang isang clip upang simulan ang pagpili, pagkatapos ay magtakda ng kategorya, paborito, o mag-delete nang maramihan.

7. Ang player

  • Tuloy-tuloy na playback: kapag natapos ang isang clip, awtomatikong nagpe-play ang susunod sa kasalukuyang listahan.
  • Susunod / Nakaraan: mula sa ⋮ menu ng player.
  • Ituloy: nagpapatuloy ang playback mula sa kung saan ka huminto.
  • Mga galaw: mag-swipe pataas/pababa sa kaliwang bahagi para sa liwanag, sa kanang bahagi para sa lakas ng tunog.
  • Bilis: i-tap ang speed button upang mag-cycle mula 0.5×–2×.
  • I-lock ang mga kontrol: itago ang mga kontrol upang maiwasan ang aksidenteng pag-tap.
  • Baguhin ang laki: i-fit, i-zoom o i-stretch ang video.
  • Picture-in-Picture at background play: patuloy na manood o makinig habang gumagamit ng ibang app.
  • Takpan ang lumulutang na teksto: gumuhit ng kahon sa ibabaw ng tekstong nasa screen o isang watermark upang itago ito habang nagpe-play (⋮ → Cover text).

8. Pag-edit ng mga clip

Mula sa ⋮ menu ng isang clip maaari mong palitan ang pangalan nito, i-edit ang paglalarawan nito, itakda ang kategorya nito, idagdag ito sa mga paborito, ilipat ito sa pribadong seksyon, o i-delete ito (opsyonal kasama ang file nito).

9. Editor ng larawan

Para sa mga naka-save na larawan maaari mong i-crop, itago ang isang pangalan o watermark gamit ang solidong kahon, magdagdag ng teksto saanman, at kunin ang teksto mula sa larawan gamit ang OCR (kinopya sa clipboard). Nase-save ang mga larawan nang malinis nang walang re-encoding artefacts.

10. Tab ng YouTube na walang ad

Mula sa ⋮ → YouTube buksan ang isang malinis na viewer na walang ad:

  • Ipinapakita ang Trending para sa rehiyon ng Arabo bilang default.
  • Isang switch ang nagtatago ng Shorts.
  • Maghanap gamit ang magnifier at i-toggle ang grid/list.

Ito ay isang hiwalay na tab at hindi kailanman pinapalitan ang iyong library. Bumalik gamit ang back button o ⋮ → Library.

11. Estadistika

Buksan ang ⋮ → Statistics para sa isang dashboard: kabuuang video, kabuuang laki, kabuuang haba at kabuuang play, kasama ang iyong pinaka-nape-play at kamakailang nape-play na mga clip at bilang ayon sa kategorya at ayon sa pinagmulan.

12. Wika, tema at mga setting

  • Wika: Settings → Language — pumili mula sa 14 na wika; agad na lumilipat ang app.
  • Tema: system, light o dark.
  • Wi-Fi lamang: mag-download lamang sa Wi-Fi.
  • Sabay-sabay na mga download: kung ilan ang nada-download nang sabay.
  • Save location: kung saan iniimbak ang kopya ng mga download.
  • Gabay ng gumagamit: palaging bumubukas ang gabay na ito sa kasalukuyang wika ng app.

13. Backup at pag-restore

Sa Settings, i-export ang isang naka-encrypt na backup ng iyong library na protektado ng password, at i-restore ito mamaya gamit ang parehong password. Ingatan ang password — kung wala ito ay hindi mabubuksan ang backup.

14. Pag-troubleshoot at FAQ

Nabigo ang isang download

Mabilis mag-expire ang mga link mula sa ilang site. Buksan ang Downloads at i-tap ang retry — kumukuha ang app ng bagong link at nagpapatuloy. Suriin ang iyong koneksyon at na ang post ay pampubliko.

Hindi nada-download ang isang post

Ang Instagram at Snapchat ay naglalantad lamang ng mga pampublikong post; ang mga pribado o login-only na post ay hindi makukuha. Ang pagkuha ay nakadepende sa platform at paminsan ay maaaring mabigo — subukan muli mamaya.

Nagpe-play ang audio bilang itim na screen

Siguraduhing pinili mo ang audio lamang noong nag-download; ang mga audio file ay nagpapakita ng cover art sa halip na isang video frame.

Nag-lock ang app sa sarili nito

Natapos ang iyong pagsubok o subscription. Ligtas ang iyong mga download — mag-renew (maglagay ng code, o mag-subscribe sa Google Play) upang magpatuloy.

May ipinapadala ba sa isang server?

Wala. Walang backend ang app. Kinokontak lamang nito ang sariling site ng video upang kunin ang hiniling mong i-download.

Iyan ang buong app. Mag-enjoy sa iyong pribadong library ng video.
