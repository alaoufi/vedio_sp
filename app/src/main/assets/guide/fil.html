Ang Aking Video Library — Gabay sa Gumagamit

Isang pribado at offline-first na library para sa pag-download at panonood ng mga video mula sa TikTok, YouTube, Instagram at Snapchat. Walang lumalabas sa iyong device.

1. Aktibasyon

Sa unang paggamit, hihingi ang app ng activation code. Nagpapakita ang iyong device ng device number; ipadala ito sa developer at ilagay ang code na matatanggap mo. Ganap na offline ang aktibasyon — walang account at walang internet na kailangan pagkatapos noon.

2. Privacy at app lock

Buksan ang Mga Setting para protektahan ang app:

  • App lock: magtakda ng PIN para hilingin ng app na i-unlock sa bawat pagbukas.
  • Fingerprint / biometric: mag-unlock gamit ang iyong fingerprint sa halip na PIN.
  • Harangan ang mga screenshot: pinipigilan ang mga screenshot at screen recording sa loob ng app.
  • Itago mula sa recents: itinatago ang preview ng app sa recent-apps switcher.

Mga pribadong video: i-lock ang anumang clip para ilipat ito sa nakatagong pribadong seksyon. Mawawala ito sa pangunahing library at babalik lang pagkatapos ng fingerprint check.

3. Pag-download ng mga video

Mula sa isang link

Kopyahin ang link ng video mula sa TikTok, YouTube, Instagram o Snapchat, pagkatapos ay i-tap ang + na button at piliin ang I-download mula sa link — o direktang ibahagi ang link sa app na ito mula sa share menu ng ibang app.

Sa pamamagitan ng paghahanap

I-tap ang search icon at mag-type ng mga keyword para maghanap sa YouTube (at TikTok). I-tap ang isang resulta para i-preview ito, o gamitin ang download button nito.

Video o audio

Kapag nag-download ka, maaari mong piliin ang buong video o audio lamang. Ang mga audio download ay naka-save bilang totoong audio file at pinapatugtog na may cover art, hindi itim na screen.

Ang Instagram at Snapchat ay nagbabahagi lamang ng mga pampublikong post. Ang mga pribado o login-only na post ay hindi maaaring i-extract.

4. Ang library

  • Grid / list view: palitan ang layout mula sa ⋮ menu → I-toggle ang view.
  • Ayusin: ayon sa petsa, pangalan, tagal, laki, o kategorya.
  • I-filter: ayon sa pinagmulan, uri ng media, at maraming kategorya nang sabay-sabay — piliin ang ilang kategorya para ipakita lang ang mga iyon at itago ang iba.
  • Mga paborito: markahan ang mga clip bilang paborito at i-filter papunta sa mga ito.
  • Mga kategorya: ayusin ang mga clip sa mga kategorya; ipinapakita ng bawat clip ang kategorya nito bilang chip. Pumili ng ilang clip para itakda ang kategorya ng mga ito nang sabay-sabay.

5. Ang player

  • Tuloy-tuloy na pagtugtog: kapag natapos ang isang clip, awtomatikong pinapatugtog ang susunod sa kasalukuyang listahan. Gamitin ang Susunod / Nakaraan mula sa ⋮ menu.
  • Ituloy: nagpapatuloy ang pagtugtog mula sa huling tinigilan mo.
  • Mga galaw: mag-swipe pataas/pababa sa kaliwang bahagi para sa liwanag, sa kanang bahagi para sa lakas ng tunog.
  • Bilis: i-tap ang speed button para umikot sa 0.5×–2×.
  • I-lock ang mga kontrol: itago ang mga kontrol para maiwasan ang aksidenteng pag-tap.
  • Picture-in-Picture at background play: magpatuloy sa panonood o pakikinig habang gumagamit ng ibang app.
  • I-resize: i-fit, i-zoom o i-stretch ang video.
  • Takpan ang lumulutang na teksto: gumuhit ng kahon sa ibabaw ng teksto sa screen o watermark para itago ito habang nagpapatugtog.

6. Walang-ad na YouTube tab

Mula sa ⋮ menu buksan ang YouTube tab: isang malinis na viewer na walang ad. Ang Trending ay ipinapakita para sa rehiyong Arabic bilang default, maaaring itago ang Shorts sa isang switch, at maaari kang maghanap at mag-toggle ng grid/list. Isa itong hiwalay na tab at hindi kailanman pumapalit sa iyong library.

7. Image editor

Para sa mga naka-save na larawan maaari mong i-crop, itago ang isang pangalan/watermark gamit ang solidong kahon, magdagdag ng teksto kahit saan, at i-extract ang teksto mula sa larawan gamit ang OCR (kinopya sa clipboard). Ang mga larawan ay nasa-save nang malinis nang walang re-encoding na artefacts.

8. Pag-edit ng mga clip

Mula sa ⋮ menu ng isang clip maaari mong palitan ang pangalan nito, i-edit ang paglalarawan nito, itakda ang kategorya nito, idagdag ito sa mga paborito, ilipat ito sa pribadong seksyon, o burahin ito.

9. Backup at pag-restore

Sa Mga Setting, mag-export ng isang naka-encrypt na backup ng iyong library na protektado ng password, at i-restore ito mamaya gamit ang parehong password. Ingatan ang password — kung wala ito, hindi mabubuksan ang backup.

10. Mga Setting

  • Wika: piliin ang wika ng app.
  • Tema: system, light o dark.
  • Wi-Fi lamang: mag-download lang sa Wi-Fi.
  • Sabay-sabay na mga download: kung ilan ang magda-download nang sabay.
  • Lokasyon ng pag-save: kung saan iniimbak ang mga download.

Iyon na ang lahat. Mag-enjoy sa iyong pribadong video library.
