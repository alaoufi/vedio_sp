Ma bibliothèque vidéo — Guide complet de l'utilisateur

Une bibliothèque privée, pensée d'abord pour le hors ligne, pour télécharger, organiser et regarder vos vidéos. Votre bibliothèque, vos téléchargements, votre base de données et votre licence résident tous sur votre appareil — rien n'est envoyé vers un serveur.

1. Activation & essai gratuit

L'application fonctionne hors ligne — aucun compte, aucune connexion Internet.

  • Essai gratuit : le premier lancement démarre automatiquement un essai gratuit de 10 jours. Vous pouvez utiliser toutes les fonctionnalités pendant cette période.
  • Après l'essai : l'application demande un code d'activation. Vos téléchargements et vos réglages sont conservés — seul l'accès est suspendu jusqu'au renouvellement.
  • Activation : l'écran d'activation affiche votre numéro d'appareil. Envoyez-le au vendeur et saisissez le code que vous recevez, puis appuyez sur Activer.
  • Statut : ouvrez Réglages → Abonnement pour voir « Essai · N jours restants », « Actif · N jours restants » ou permanent.
Sur Google Play, l'application peut s'activer automatiquement dès que votre abonnement est actif — aucun code n'est nécessaire.

2. Confidentialité & verrouillage de l'application

Tout se trouve dans Réglages → Sécurité :

  • Verrouillage de l'application : définissez un code PIN pour que l'application demande à être déverrouillée à chaque ouverture.
  • Empreinte / biométrie : déverrouillez avec votre empreinte digitale au lieu de taper le code PIN.
  • Bloquer les captures d'écran : empêche les captures d'écran et l'enregistrement de l'écran dans l'application.
  • Masquer des applications récentes : masque l'aperçu de l'application dans le sélecteur d'applications récentes.

Vidéos privées

Verrouillez n'importe quel clip (depuis son menu ⋮) pour le déplacer vers la section privée masquée. Il disparaît de la bibliothèque principale et ne réapparaît qu'après une vérification d'empreinte digitale (ouvrez la vue privée depuis le menu ⋮).

3. Télécharger des vidéos

Depuis un lien

  1. Copiez un lien de vidéo.
  2. Appuyez sur le bouton + → Télécharger depuis un lien (ou partagez le lien vers cette application depuis une autre application).
  3. Appuyez sur Coller, puis sur Obtenir les infos.
  4. Choisissez vidéo complète, vidéo uniquement ou audio uniquement, puis téléchargez.

Par recherche

Appuyez sur l'icône de recherche, saisissez des mots-clés, appuyez sur un résultat pour l'aperçu, ou utilisez son bouton de téléchargement.

Audio ou vidéo

Les téléchargements audio sont enregistrés comme de vrais fichiers audio et se lisent avec une pochette (pas un écran noir). Vous pouvez aussi choisir une qualité lorsque la source en propose plusieurs.

Où vont les fichiers

Les téléchargements sont stockés de façon privée dans l'application. Dans Réglages → Emplacement d'enregistrement, vous pouvez aussi faire placer une copie dans un dossier de votre choix afin qu'elle apparaisse dans votre galerie ou votre gestionnaire de fichiers.

4. Le navigateur intégré

Ouvrez + → Navigateur pour un navigateur web général qui détecte les médias téléchargeables sur n'importe quelle page.

  1. Saisissez un site ou une recherche dans la barre d'adresse.
  2. Lisez ou ouvrez la vidéo sur la page.
  3. Lorsqu'un média est détecté, un bouton Télécharger (N) apparaît — appuyez dessus, choisissez l'élément, et il se télécharge dans votre bibliothèque.
Le navigateur continue d'analyser la page pendant quelques secondes ; donc si le bouton n'apparaît pas immédiatement, lancez la vidéo et patientez un instant.

5. Gérer les téléchargements

Ouvrez + → Téléchargements (ou appuyez sur la bannière de téléchargement dans la bibliothèque) pour voir les tâches en cours et terminées. Vous pouvez mettre en pause, reprendre et relancer. Les téléchargements en pause ou interrompus reprennent là où ils se sont arrêtés, et un téléchargement échoué actualise automatiquement son lien et réessaie.

6. La bibliothèque

  • Vue grille / liste : basculez depuis ⋮ → Toggle view.
  • Recherche : appuyez sur la loupe ; elle filtre la bibliothèque en temps réel.
  • Tri : par date, nom, durée, taille ou catégorie (regroupe les clips par catégorie).
  • Filtre : par source, type de média et plusieurs catégories à la fois — cochez les catégories à afficher et le reste est masqué. L'entrée Catégorie indique combien sont actives.
  • Favoris : marquez des clips comme favoris et filtrez pour ne voir qu'eux.
  • Catégories : chaque clip affiche sa catégorie sous forme de puce. Gérez les catégories depuis ⋮ → Manage categories.
  • Sélection multiple : appuyez longuement sur un clip pour démarrer la sélection, puis définissez une catégorie, marquez comme favori ou supprimez en lot.

7. Le lecteur

  • Lecture continue : lorsqu'un clip se termine, le suivant dans la liste en cours se lit automatiquement.
  • Suivant / Précédent : depuis le menu ⋮ du lecteur.
  • Reprise : la lecture reprend là où vous vous êtes arrêté.
  • Gestes : glissez vers le haut/bas sur la moitié gauche pour la luminosité, sur la moitié droite pour le volume.
  • Vitesse : appuyez sur le bouton de vitesse pour faire défiler de 0,5× à 2×.
  • Verrouiller les commandes : masquez les commandes pour éviter les appuis accidentels.
  • Redimensionner : ajuster, zoomer ou étirer la vidéo.
  • Picture-in-Picture & lecture en arrière-plan : continuez à regarder ou à écouter tout en utilisant d'autres applications.
  • Masquer un texte flottant : dessinez un cadre sur un texte affiché ou un filigrane pour le masquer pendant la lecture (⋮ → Cover text).

8. Modifier les clips

Depuis le menu ⋮ d'un clip, vous pouvez le renommer, modifier sa description, définir sa catégorie, l'ajouter aux favoris, le déplacer vers la section privée ou le supprimer (avec son fichier, éventuellement).

9. Éditeur d'images

Pour les images enregistrées, vous pouvez rogner, masquer un nom ou un filigrane avec un cadre plein, ajouter du texte n'importe où, et extraire le texte de l'image avec l'OCR (copié dans le presse-papiers). Les images sont enregistrées proprement, sans artéfacts de réencodage.

10. Onglet YouTube sans publicité

Depuis ⋮ → YouTube, ouvrez une visionneuse épurée sans publicité :

  • Les tendances sont affichées pour la région arabe par défaut.
  • Un interrupteur masque les Shorts.
  • Recherchez avec la loupe et basculez entre grille et liste.

C'est un onglet distinct qui ne remplace jamais votre bibliothèque. Revenez avec le bouton retour ou ⋮ → Library.

11. Statistiques

Ouvrez ⋮ → Statistics pour un tableau de bord : nombre total de vidéos, taille totale, durée totale et nombre total de lectures, ainsi que vos clips les plus lus et récemment lus, et les décomptes par catégorie et par source.

12. Langue, thème & réglages

  • Langue : Réglages → Langue — choisissez parmi 14 langues ; l'application bascule instantanément.
  • Thème : système, clair ou sombre.
  • Wi-Fi uniquement : télécharger uniquement en Wi-Fi.
  • Téléchargements simultanés : combien peuvent se télécharger en même temps.
  • Emplacement d'enregistrement : où une copie des téléchargements est stockée.
  • Guide de l'utilisateur : ce guide s'ouvre toujours dans la langue actuelle de l'application.

13. Sauvegarde & restauration

Dans Réglages, exportez une sauvegarde chiffrée de votre bibliothèque protégée par un mot de passe, et restaurez-la plus tard avec le même mot de passe. Conservez le mot de passe en lieu sûr — sans lui, la sauvegarde ne peut pas être ouverte.

14. Dépannage & FAQ

Un téléchargement a échoué

Les liens de certains sites expirent rapidement. Ouvrez Téléchargements et appuyez sur relancer — l'application récupère un lien à jour et continue. Vérifiez votre connexion et que la publication est publique.

Une publication ne se télécharge pas

Instagram et Snapchat n'exposent que les publications publiques ; les publications privées ou accessibles uniquement après connexion ne peuvent pas être extraites. L'extraction dépend de la plateforme et peut occasionnellement échouer — réessayez plus tard.

L'audio se lit comme un écran noir

Assurez-vous d'avoir choisi audio uniquement lors du téléchargement ; les fichiers audio affichent une pochette au lieu d'une image vidéo.

L'application s'est verrouillée toute seule

Votre essai ou votre abonnement a pris fin. Vos téléchargements sont en sécurité — renouvelez (saisissez un code, ou abonnez-vous sur Google Play) pour continuer.

Quelque chose est-il envoyé à un serveur ?

Non. L'application n'a aucun backend. Elle contacte uniquement le site de la vidéo pour récupérer ce que vous avez demandé à télécharger.

Voilà toute l'application. Profitez de votre bibliothèque vidéo privée.
